# Yerkhat Takatbek

I build AI products and study how AI agents behave after they're deployed. Kazakhstan. Kazakh, Russian, English.

## Research

**[agent-instruction-files](https://github.com/Yerkhat1/agent-instruction-files)**: what the rules in `CLAUDE.md` and `AGENTS.md` actually do, measured across 753 rules in 410 public repositories. Two thirds of them describe code that already complies. Among rules that ask for real change, the ones backed by a linter or type checker close about three times more of the remaining gap than rules written only as prose. Dataset, pipeline, and a script that recomputes every number are in the repo.
