I build AI systems and study how they behave once they are deployed. Kazakhstan. Kazakh, Russian, English.

## Research

**[agent-instruction-files](https://github.com/Yerkhat1/agent-instruction-files)** — do the rules people write into `CLAUDE.md` and `AGENTS.md` actually change the code? Measured across 753 rules in 410 public repositories using AST checks, no model judging. Two thirds of rules describe code that already complied. Among the rules that did ask for change, those backed by a linter closed about three times more of the remaining gap than rules written only as prose, and both groups edited a similar share of their files, so the difference is not reach. Dataset, pipeline and a script that recomputes every published figure are in the repo.
